STAGE 2 - PROCESSING
====================

This credential-free public installer adds:
  - Stage 2 v1.4.1 - Obsidian Compact
  - Desktop and Start Menu shortcuts
  - the in-app user guide

It does not require a GitHub account or repository invitation and does not
include an API key, bot tokens or an automatic LibreOffice installation.

FIRST RUN
---------
Open Settings (the cog), paste your Anthropic API key, and save it. The key is
stored in Windows Credential Manager, not in a file, and survives app updates.

LibreOffice is recommended for supported Word, Excel and PowerPoint conversion.
If it is missing, install it once with:
  winget install --id TheDocumentFoundation.LibreOffice -e

Preserve originals and review important source content. Conversion completion
and the filename audit do not guarantee that signatures, cells, form values or
layout were preserved. Unreadable or incomplete documents need honest review,
not a guessed filename or a passed-audit claim. See Guide for next steps.

Existing settings, API credentials and processed documents are not removed or
overwritten by an update.

LOCAL PAGE ORIENTATION
----------------------
The bundled CPU-only model checks PDF pages locally and never downloads at
runtime. New configurations start in Audit only / shadow mode; updates retain
existing settings. Review its report before
enabling automatic high-confidence correction in Settings.
